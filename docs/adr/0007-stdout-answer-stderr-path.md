# 0007. 답은 stdout, 위임 경로는 stderr로 분리

- 상태: 채택
- 날짜: 2026-07-13

## 맥락
결과가 `dig +short`와 같은지 스크립트로 비교해야 한다. 동시에 루트부터 내려간 위임 경로도 보여줘야 한다.

## 결정
- 최종 레코드는 `dig +short` 형식으로 stdout에 쓴다.
- 위임 경로, 캐시 히트, `-v` 로그는 stderr에 쓴다 (`src/main.c`).
- 모든 도메인이 레코드로 풀려야 exit 0.

## 대안
- 한 스트림에 출력: stdout만 떼어 `dig +short`와 비교할 수 없다.

## 결과
- 장점: `tests/compare_dig.sh`가 stdout만 집합 비교한다.
- 단점/감수한 점: 경로를 파일로 남기려면 stderr를 따로 리다이렉트해야 한다.
